# KATHAINV

Proyecto fullstack TypeScript con Next.js, Tailwind y sistema de datos JSON.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run type-check`
- `npm run test`

## Estructura principal

- `src/app` — rutas y páginas de Next.js
- `src/components` — componentes reutilizables
- `data` — colecciones y documentación JSON
- `doc` — plan de implementación
